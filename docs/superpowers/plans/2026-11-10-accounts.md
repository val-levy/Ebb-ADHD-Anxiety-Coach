# Ebb Accounts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real accounts through Supabase Auth with Sign in with Apple, a `profiles` table, and the panic ladder and locks for anonymous users.

**Architecture:** `AuthService` is the only code that touches `client.auth`. `SessionStore` publishes `isSignedIn`, `profile` and the panic decision. Views read the store, and logic stays in models and services. `PanicGate` is pure and checks itself in DEBUG, like `Tip.selfCheck()`.

**Tech Stack:** SwiftUI (iOS 17), supabase-swift, AuthenticationServices, CryptoKit (nonce), Security (Keychain), Supabase Postgres and Edge Functions (Deno).

**Spec:** `docs/superpowers/specs/2026-11-10-accounts-design.md`

## Global Constraints

- Sign in with Apple only, through Supabase `signInWithIdToken(provider: .apple, idToken:, nonce:)`.
- Username: 3–20 chars, `^[a-z0-9_]+$`, stored lowercase, unique. display_name: 1–40 chars. bio: ≤160 chars or null. animal: default `'panda'`.
- "Signed in" means a `profiles` row exists for the current user. Anonymous users, or users linked to Apple with no profile, are not signed in.
- Panic ladder by uses started while not signed in: 0 prior uses → `.free` (`.promptAfter`); 1 → `.promptBeforeSkippable`; 2 or more → `.blocked`. The counter lives in the Keychain and is never reset.
- The blocked screen always shows 988 Call (`tel:988`) and Text (`sms:988`).
- Never put the service role key or any secret in the app or repo. Never commit Config.xcconfig.
- One type per file, no logic in views, clay style, `ClayFont.*`, and respect Reduce Motion (CLAUDE.md).
- The user has no paid Apple Developer account. Add the entitlement now, but keep phone builds for the free team `F2DD8TWKAQ` working (see Task 7).
- No git repo. Each task ends with an entry in `.claude/progress/accounts/progress.md`, using a real time from `date`.

## Review Focus

- Network down at launch: anonymous sign-in fails. Panic must still open (`.free`/ladder from Keychain), never a spinner or crash.
- Username taken between the availability check and the insert: the unique violation (23505) shows "That name was just taken" on the sheet, and the sheet stays open.
- Setup sheet closed after Apple linking: still not signed in, and the next locked tap reopens setup, not Apple.
- Linking an Apple ID that already has an account (`identity_already_exists`): fall back to a fresh Apple prompt and `signInWithIdToken`.
- Mixed-case or spaced username input: lowercased and trimmed before validating and checking.
