# Phase 3: After launch (v2)

Status: **not started, intentionally** · Source: product-spec.md, "MVP scope" · Master: [roadmap.md](roadmap.md)

Out of scope for the MVP per the spec. Listed so nothing is lost.

- **Intervention picker:** learns which reset works for which state, time and place (a contextual bandit) and offers
  that one first. Builds on what-helped data already recorded.
- **"One next thing":** say what's overwhelming; an on-device language model returns one 5-minute starting step.
  Optional, recent iPhones only; core resets never need it. (0 code today.)
- **Brain dump with a language model:** brain dump exists as a text card; v2 files dictated items automatically.
- **Bluetooth heart-rate mode:** Polar Verity Sense / H10 over Core Bluetooth for all-day live heart rate and real HRV.
- **Therapist export:** a PDF of patterns for between-session homework.
- **Later platforms:** Wear OS / other bands once the core works.
